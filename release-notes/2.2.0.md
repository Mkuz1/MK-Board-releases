## MK Board 2.2.0

- **Arabic keyboard now matches the iPhone layout exactly.** Letters are arranged as on iOS, delete is the last key of the third row, and there's no shift key.
- **New tashkeel (diacritics) key.** Tap for tanween (ً) or hold for all the harakat: َ ُ ِ ٌ ٍ ْ ّ.
- **Arabic-Indic numerals** `١٢٣` on the number page (hold a digit for 1 2 3), with Arabic punctuation ، ؛ ؟. You can switch back to Western digits in settings.
- **iOS 27 Liquid Glass look.** Flatter, softly translucent keys with continuous rounded corners. Function keys match the letter keys. The return key shows an arrow, mirrored for Arabic. The emoji key is filled. A small language badge (ع / EN) sits on the space bar, and the keyboard sheet has rounded corners top and bottom.
- Refreshed Liquid Light and Liquid Dark themes, colour-matched to iOS.
