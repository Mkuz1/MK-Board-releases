## MK Board 3.0.1: fits every app and screen properly

- **No more covering the message box.** The keyboard uses Android's standard keyboard placement again, so WhatsApp and other apps make room for it correctly, including on foldables and on phones with gesture navigation.
- **No duplicate buttons.** Android already shows hide-keyboard and switch-keyboard buttons under the keyboard, so MK Board's globe / dictation strip is now off. The keyboard is about 45 dp shorter. 🌐 appears on the keyboard only when you've enabled more than one language. You can turn the strip back on in Settings → Design.
- **Shortcuts button removed** from the keyboard. Hold 😊 for 📋 clipboard, 💬 text shortcuts, 🎙 voice typing, and one-handed ◀ ▣ ▶.
- **Floating keyboard: new dock button** beside the drag handle returns it to the bottom.
- Slightly lower maximum keyboard height, so apps keep more room.
